MultiSoft Cleaner (Free)

Limpiador de disco: analiza espacio, encuentra duplicados y archivos grandes, limpia basura y genera informes. Edición Free con límites; Pro amplía capacidades.

Descargar solo este proyecto (ZIP)

Opción A — ZIP (recomendada)

  1. Descarga el ZIP de arriba.
  2. Descomprime la carpeta.
  3. En Windows o Linux:
cd MultiSoftCleaner
pip install -r requirements.txt
python main.py

En Windows también puedes usar el flujo de build del workflow (PyInstaller) cuando esté en el repo de la org.

Opción B — Solo esta carpeta desde Git (sparse checkout)

Descarga únicamente Descargables/MultiSoftCleaner, no todo el portafolio.

mkdir MultiSoftCleaner && cd MultiSoftCleaner
git init
git remote add origin https://github.com/MultiSoftCreations/Portafolio.git
git config core.sparseCheckout true
echo "Descargables/MultiSoftCleaner/*" >> .git/info/sparse-checkout
git pull origin main
cd Descargables/MultiSoftCleaner
pip install -r requirements.txt
python main.py

Límites Free vs Pro

  • Free: hasta 30 archivos grandes, 40 grupos de duplicados; sin export HTML ni filtros avanzados.
  • Pro: límites ampliados, export HTML, filtros avanzados e historial completo.
