MultiSoft NetGuard

Sistema de protección / monitor de red offline. Detecta puertos abiertos, procesos y tráfico inusual. Compatible con Termux y Linux.

Descargar solo este proyecto (ZIP)

Opción A — ZIP (recomendada)

  1. Descarga el ZIP de arriba.
  2. Descomprime la carpeta.
  3. En Termux o Linux:
cd MultiSoftNetGuard
pkg install python git   # Termux
pip install -r requirements.txt
python main.py

Opción B — Solo esta carpeta desde Git (sparse checkout)

No clona todo el portafolio: solo Descargables/MultiSoftNetGuard.

mkdir MultiSoftNetGuard && cd MultiSoftNetGuard
git init
git remote add origin https://github.com/MultiSoftCreations/Portafolio.git
git config core.sparseCheckout true
echo "Descargables/MultiSoftNetGuard/*" >> .git/info/sparse-checkout
git pull origin main
cd Descargables/MultiSoftNetGuard
pip install -r requirements.txt
python main.py
