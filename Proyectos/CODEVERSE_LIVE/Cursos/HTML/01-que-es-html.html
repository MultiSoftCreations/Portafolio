¿Qué es HTML?

HTML significa HyperText Markup Language (lenguaje de marcado de hipertexto). No es un lenguaje de programación como Python o JavaScript: es un lenguaje de marcado que describe la estructura del contenido de una página web.

Cuando abres un sitio, el navegador lee el HTML y dibuja títulos, párrafos, imágenes y enlaces según las etiquetas que escribiste.

Idea clave

  • HTML → estructura y contenido
  • CSS → apariencia (colores, tamaños, diseño)
  • JavaScript → comportamiento e interactividad

Una etiqueta simple

<p>Hola, mundo</p>

La etiqueta <p> abre un párrafo y </p> lo cierra. Casi todo en HTML funciona con apertura y cierre.
