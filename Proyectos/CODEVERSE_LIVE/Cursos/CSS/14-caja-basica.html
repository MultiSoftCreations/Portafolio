Caja: margin, padding y border

Analogía: regalo

  • padding → aire dentro de la caja (entre el borde y el contenido)
  • border → el cartón del borde
  • margin → espacio fuera, respecto a otras cajas
.intro {
  padding: 12px;
  border: 2px solid #6c5ce7;
  margin: 16px 0;
}
